# Texturas dos marcadores

Os marcadores usam texturas PNG do Minecraft Java 1.8.8, baixadas durante o
GitHub Actions a partir do repositório:

https://github.com/InventivetalentDev/minecraft-assets

Arquivos usados:

- items/emerald.png — vila
- blocks/sandstone_normal.png — templo do deserto
- blocks/cobblestone_mossy.png — templo da selva
- items/cauldron.png — cabana de bruxa
- blocks/prismarine_dark.png — monumento oceânico
- blocks/rail_normal.png — mina abandonada
- items/bed.png — spawn
